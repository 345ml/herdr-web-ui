### Changed
- The chat's `/` menu lists the commands that run in the terminal apart, last, under Terminal
  commands, each with a Terminal badge, as the PC's command catalog describes them. Pick or type
  one and send it normally: once accepted, this browser opens Terminal with a dismissible command
  hint and Back to Chat, which returns to the reader's previous position. Busy commands stay
  queued; only an explicit Send now switches views, never automatic delivery. Refused sends keep
  their draft and note. Watch-only devices never send or switch, and /resume still opens Earlier
  sessions. Commands the agent's own menu hides are not listed, but still go when typed by hand.
- For an OpenCode pane whose skills are `@` attachments, the `@` menu lists them under Skills
  before the files, and picking one inserts the skill's id.
