### Added
- Mod+Shift+A, or **Next agent needing attention** in the command palette, opens the next agent that
  waits for you on any connected PC: the ones that need input first, then the finishes nobody has
  looked at yet, in the order the Agents list shows them (pinned first), round and round. A finish
  opened this way reads as seen, as it does from the sidebar, and leaves the cycle; with nothing
  waiting the key does nothing. Only this browser's selection moves: herdr's own focus, its TUI and
  your other devices stay where they are. The binding can be changed or turned off in Settings →
  Shortcuts like the others.
